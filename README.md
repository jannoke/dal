# DAL (archived)

DAL, the per-vhost Apache log splitter, lives in [jannoke/datapanel](https://github.com/jannoke/datapanel) as
`dataserver/dal/` since 2026-11-02, where it became DAL 2 (tenants' logs written as the tenant, bandwidth straight to
MySQL) and DAL 2.1 (ProFTPD's log). Work on it there.

This repo keeps its history up to then: the C++ `dal-1.2.1` and the first Rust port. It stays as it was, read-only,
so its pull requests and commit links keep working.
